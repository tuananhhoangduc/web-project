# Barber Shop — Dự án đặt lịch cắt tóc

Mô tả : Website cho phép người dùng đặt lịch cắt tóc trực tuyến; quản trị viên quản lý tiệm cắt tóc và thợ cắt quản lý lịch làm việc.

Chức năng chính

- Người dùng: đăng ký/đăng nhập, xem dịch vụ, chọn thợ, đặt lịch, xem lịch sử và gửi đánh giá.
- Quản trị viên: quản lý khách hàng, thợ, chi nhánh, dịch vụ; xem thống kê và điều chỉnh lịch.
- Thợ cắt: xem lịch cắt, gửi đơn xin nghỉ phép

 
Công nghệ

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Hosting : InfinityFree
